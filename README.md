# telegram-bots

Nix-configured Telegram bots: a long-poll daemon plus a unix control socket per
instance. Every instance can **notify** and **ask** (blocking reply). Optional
slash `commands` and guest mode are configured in Home Manager.

Formerly `agent-telegram-bot`.

## CLI

```bash
# Long-poll daemon (systemd sets --instance)
telegram-bots --instance agent daemon

# Fire-and-forget notice
telegram-bots --instance agent notify --role vuln-monitor "build finished"

# Block until a Telegram reply (or timeout)
telegram-bots --instance agent ask --role agent --timeout 600 "Ship it?"

# Check the control socket
telegram-bots --instance agent ping
```

Message body can be a positional argument or stdin. `--instance` can also come
from `TELEGRAM_BOTS_INSTANCE`.

## Daemon environment

| Variable | Purpose |
|----------|---------|
| `TELEGRAM_BOTS_INSTANCE` | Instance id (attrs key) |
| `TELEGRAM_BOTS_TOKEN_FILE` | Path to Bot API token file |
| `TELEGRAM_BOTS_SETTINGS` | JSON settings generated by the HM module |
| `STATE_DIRECTORY` | Daemon only: state dir (socket + persisted state) |
| `TELEGRAM_BOTS_SOCKET` | Optional override for the control socket path |

Daemon socket: `$STATE_DIRECTORY/telegram-bots.sock` (or `TELEGRAM_BOTS_SOCKET`).
CLI notify/ask/ping ignore `STATE_DIRECTORY` and use `TELEGRAM_BOTS_SOCKET` or
`~/.local/state/telegram-bots-<instance>/telegram-bots.sock`.

## Nix / Home Manager

```nix
{
  inputs.telegram-bots.url = "github:danieloakman/telegram-bots";
  # During migration from the old repo name:
  # inputs.telegram-bots.url = "github:danieloakman/agent-telegram-bot";

  imports = [ inputs.telegram-bots.homeManagerModules.default ];

  services.telegram-bots.instances = {
    agent = {
      enable = true;
      chatIds = [ 123456789 ];
      allowedUserIds = [ 123456789 ];
      tokenFile = config.sops.secrets.agent_telegram_bot_token.path;
    };
  };
}
```

Secrets stay in the consumer flake. Overlay: `overlays.default` exposes
`pkgs.telegram-bots`.

Slash commands, guest mode, interpreter, and ask multiple-choice land next;
settings/HM options for them are already reserved.
